# One Life

A single-file life simulation game: live a whole life one year at a time, from birth to obituary, with careers, money, markets, property, relationships, businesses, challenges and multi-generation dynasties.

## Play

Open `index.html` in a browser. Progress is saved in the browser's `localStorage`.

The optional ✨ AI storyteller (Menu) works only when the page is opened as a Claude artifact.

Published artifact: https://claude.ai/artifact/6DBbnkycFfx87e76B5App6
